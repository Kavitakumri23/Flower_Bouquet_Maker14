# Flower Bouquet Maker
A Python mini project with a Tkinter graphical user interface.

## Features
- Choose flowers and quantities
- Select wrapping style
- Enter customer name and an optional message card
- Choose pickup or home delivery
- Calculate total bill
- Place an order and save the receipt to a local `receipts` folder

## Requirements
- Python 3.x
- Tkinter (usually included with Python)
- No external packages required

## Run
Open a terminal in this folder and run:
`python main.py`

## Concepts used
Dictionaries, classes, loops, functions, GUI widgets, event handling, validation, date/time, and file handling.
